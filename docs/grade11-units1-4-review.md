# Grade 11 Units 1–4 exercise refinement

The existing original audio, bilingual captions, subtitle persistence, shadowing, Grade 10 components and shared billing/provider helpers remain unchanged.

- Unit 1 Speaking B uses a bilingual question-bank table with direct dialogue translations. C and D expose the existing Grade 11 AI speaking component with a server-validated exercise identifier. Only one embedded exercise can be open at a time. C uses the completed textbook trip dialogue; D uses the textbook's local-lake birdwatching task. Existing speaking sessions/quotas apply.
- Unit 2 Reading A has a single group check, direct statement translations and no per-statement checking/reveal controls. Reading B uses semantic AI feedback for the student's own sentences, including personal opinions. Grammar A translations were corrected without changing the English questions. Grammar uses the Grade 10 text/oral explanation component with source examples, real formulas and walkthroughs. One Tips disclosure is provided per lesson. Writing drafts can be reviewed through the existing authenticated checking route.
- Unit 3's memory diagram on printed page 24 is transcribed into a table, preserving the information/sensory memory/attention/working memory/encoding/long-term memory/retrieval sequence. Reading A is a definition/answer table, B uses compact exercise cards, and the two poem extracts in C are grouped with direct translations. The original-page-24 image link is omitted. Grammar uses the shared text/oral style. Speaking expressions and dialogues use tables and direct translations; the Nilar prompt was transcribed from the source page instead of dropping it with the old scan.
- Unit 4 uses grouped checking, a matching table for food vocabulary, shared text/oral grammar explanations with source examples, an editable four-student survey and a structured writing planner with a collapsible sample essay. Free writing can be reviewed with AI.
- Review 1 B4 uses the exact task supplied by the teacher in chat and accepts an after-clause answer. Poem 1 pre-reading no longer offers question-structure controls; comprehension structures remain.

`listeningExerciseKeys.json` supplies the formerly missing Unit 2–4 listening answers. Picture order was checked against the Unit 2 source scan; answer evidence refers to the supplied MP3-derived cue IDs and audio hashes. Personal survey answers are never compared against a fixed key.

`Grade11ExerciseCard` stores field values in the existing workspace draft keys. A local group check is invalidated as soon as its answers change. AI review is explicit, authenticated and never automatic. Pending client checks are cancelled when the answer changes or the component unmounts; stale replies are ignored. The existing `/api/g11-check` adapter now accepts up to 12,000 answer characters and gives writing-specific feedback, avoiding the former 800-character truncation. No model, credential, database or credit/quota configuration is changed. Live paid provider requests require a signed-in account and are separate from mock tests.
